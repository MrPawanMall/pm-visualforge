# Changelog

## 1.0.0 — 2026-11-17
First release of **PM VisualForge** by Pawan Mall.
- Visual canvas: select elements, edit text inline, drag to move, right-click menu and keyboard shortcuts
- Style inspector that writes inline styles, class rules, external CSS files and responsive media queries
- Layers tree with drag reorder, an Insert library of 40+ blocks, and a Pages panel
- Live preview server with browser auto-reload and CSS hot-swap
- Image editor: crop, rotate, flip, straighten, resize, adjust, filters, WebP export and alt text
- Link manager with broken-link detection and bulk actions, plus a link dialog
- Color Studio: HEX/RGB/HSL/HWB/OKLCH, eyedropper, page palette, CSS variables, harmonies, shades, WCAG contrast with auto-fix, and a gradient builder
- Page settings & SEO with a Google preview, plus an accessibility/SEO audit
- Tutorial mode with a guided tour and hover hints; About panel
